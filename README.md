# MSA-3-NovaMarket

Проектная работа спринта 3 курса «Разработка нагруженных микросервисных приложений под
Event-Driven архитектуру». Проектирование e-commerce-маркетплейса **NovaMarket** на событийной
архитектуре (EDA), масштабирование под нагрузку в Kubernetes и повышение надёжности на NGINX.

**Бизнес-контекст:** MVP маркетплейса (каталог, оформление заказа, оплата, доставка, история,
уведомления), рост с 2500 до 40 000+ заказов/день. Деплой в Kubernetes, API-gateway и прокси —
NGINX. NFR отклика: ≤1 c в 99,99%, 0,3 c в 98%.

## Состав репозитория

| Директория | Задание | Содержимое |
|---|---|---|
| [Task1/](./Task1) | EDA-архитектура + Saga | C2-диаграмма (C4) сервисов и потоков событий; реестр событий Saga оформления заказа; sequence-диаграммы успешного и ошибочных сценариев |
| [Task2/](./Task2) | Агрегация на фронте | Обновлённая C2 с просмотром истории заказов; ADR с выбором паттерна (CQRS) |
| [Task3/](./Task3) | Масштабирование под нагрузку | K8s-манифесты (Deployment, Service, HPA по памяти и по RPS), Prometheus + prometheus-adapter, locustfile, логи прогона масштабирования |
| [Task4/](./Task4) | Надёжность | Конфиги NGINX: rate limiter (web 50 r/s, mobile 30 r/s) и circuit breaker (3 c / 5 ошибок → 30 c, fallback); locust-сценарии и логи срабатывания |
| [assignment/](./assignment) | Исходное задание | Оригинал HTML + причёсанный текст и критерии приёмки |

## Как читать

Каждая задача снабжена своим `README.md` с описанием решения и инструкцией воспроизведения.
Диаграммы выполнены в PlantUML (C4-PlantUML / UML Sequence) с отрендеренными `*.png`.

Рендер всех диаграмм:

```bash
docker run --rm -v "$PWD/Task1:/work" -w /work plantuml/plantuml -tpng "*.puml"
docker run --rm -v "$PWD/Task2:/work" -w /work plantuml/plantuml -tpng "*.puml"
```
